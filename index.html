Bắt đầu

Cài đặt trong bốn bước

Cần Minecraft 1.21.11, Fabric Loader, Fabric API, Meteor Client và JDK 21 khi chạy game.

Yêu cầu hệ thống

  • Minecraft 1.21.11
  • Fabric Loader 0.18.x
  • Fabric API
  • Meteor Client SNAPSHOT
  • Baritone 1.15.0 (cài rời)
  • Java 21 trở lên

Baritone không được bundle trong jar. Tải baritone-fabric-1.15.0.jar và đặt cạnh mod chính.

  1. Tải bản mới nhất tại dsc.gg/herlysaddon

    Vào server Discord chính thức, mở kênh tải xuống và lấy đúng file cho nền tảng của bạn. Miễn phí, không cần license.

  2. Đóng game hoàn toàn

    Không chép đè jar khi Minecraft đang chạy — hash check sẽ fail-closed.

  3. Mở thư mục mods của instance

    Đặt HerlysAddon-1.21.11.jar cạnh meteor-client và Baritone.

  4. Khởi động game

    Vào Meteor → Modules, kiểm tra ba nhóm HERLYSADDON, HERLYS_PVP, HERLYS_ESP.

  5. Bật module và gán keybind

    Chuột phải trong ClickGUI để mở setting, chỉnh theo nhu cầu.

  1. Chuẩn bị JDK 21

    Biến JAVA_HOME phải trỏ tới JDK 21. Toolchain build dùng Gradle wrapper của repo.

  2. Clone source và build

    git clone <repo> HerlysAddon
cd HerlysAddon
build.cmd          # Windows: release
./gradlew build    # hoặc Gradle trực tiếp

  3. Chạy gate kiểm thử

    powershell -NoProfile -ExecutionPolicy Bypass -File .\vmcheck.ps1

    Exit code 0 = interpreter VM và pipeline test đều xanh. Vi phạm thì không deploy.

  4. Lấy jar thành phẩm

    File nằm ở build/libs/HerlysAddon-1.21.11.jar. Bản -dev.jar là intermediate, không phát hành.

  1. herlys-config.php

    Endpoint cấu hình tập trung: mod fetch endpoint và key lúc chạy, cache 6 giờ — xoay key không cần rebuild.

  2. ai/gpt-oss-120b.php

    Proxy AI cho lệnh .ai. Cần API key Groq cấu hình phía server.

  3. herlyschat/

    Chat chung cross-server, lưu bằng JSON, không cần database.

Chi tiết triển khai xem server/README_DEPLOY.md trong repo.

Windows nhận bản đầy đủ (payload + native host + guard). macOS hiện là jar-only, chạy ở chế độ degraded cho tới khi native host cho mac phát hành.

Kiến trúc

Bảo vệ bản phát hành, không phải trang trí

Bản release đi qua pipeline obfuscation nhiều lớp: string vault, envelope mã hoá, VM bytecode, kiểm tra toàn vẹn và guard chống phân tích. Tất cả nhằm giữ logic khỏi công cụ dịch ngược tự động — người dùng vẫn tải và dùng miễn phí.

7lớp obfuscation
2.7k+method virtualized
AES-256GCM per shard
0string plaintext trong shard

String vault

Toàn bộ chuỗi và concat được đưa vào payload shard, callsite chỉ còn cặp int. Key gắn với build và DLL.

Envelope HERLYSE2

Mỗi shard bọc AES-256-GCM với nonce riêng, AAD gồm DLL FNV và index — shard bị đổi chỗ chết ngay tại tag.

VM bytecode

Method được dịch sang chương trình của interpreter riêng, chia thành nhiều piece, chỉ cài khi đủ toàn bộ.

Anti-tamper

Kiểm tra FNV-1a/64 mỗi lần load, marker set và guard watchdog chạy nền; lệch hash là dừng an toàn.

Split loader

Chế độ sealed giữ implementation trong DLL overlay; jar chỉ khai báo roster, loader định nghĩa class lúc runtime.

Agent watch

Phát hiện JDWP, attach listener, tool dump và java agent lạ trước khi payload được định nghĩa.

HerlysAddon được phát hành miễn phí cho cộng đồng. Các lớp bảo vệ ở trên không phải paywall — chúng giữ logic khỏi công cụ dịch ngược tự động và các bản re-upload chỉnh sửa. Bản chính thức luôn nằm ở dsc.gg/herlysaddon.

Hỏi đáp

Câu hỏi thường gặp

HerlysAddon có miễn phí không?

Có — hoàn toàn miễn phí. Không có paywall, không cần license hay key. Bạn chỉ cần vào Discord chính thức và tải file về. Một số ghi chú cũ ghi "trả phí" là để hạn chế công cụ và AI tự động dịch ngược, không phải điều kiện sử dụng.

Tải bản mới nhất ở đâu?

Tại dsc.gg/herlysaddon — kênh phát hành chính thức duy nhất. Trong server có kênh tải xuống riêng cho Windows và macOS. Không tải từ nguồn lạ để tránh bản bị chỉnh sửa.

Ai phát triển addon này?

HerlysAddon được phát triển bởi DragonHerlys và Tr0ngX, phát hành miễn phí cho cộng đồng Meteor.

Cần những mod gì để chạy?

Minecraft 1.21.11, Fabric Loader, Fabric API, Meteor Client bản snapshot và Baritone 1.15.0 đặt trong thư mục mods. Java 21 là bắt buộc.

Vì sao Baritone không nằm trong jar?

Baritone được khai báo modCompileOnly / modRuntimeOnly để tránh bundle trùng phiên bản. Bạn tự đặt file jar vào mods.

Bản macOS khác gì bản Windows?

Bản Windows có native host và guard đầy đủ. Bản macOS hiện chỉ là jar, chạy degraded cho tới khi native host cho mac được phát hành.

Build báo remapJar UP-TO-DATE nhưng jar vẫn cũ?

Xoá build/libs/HerlysAddon-*.jar rồi build lại. Gradle giữ jar cũ nếu task bị coi là up-to-date.

Addon có né được mọi anti-cheat không?

Không có cam kết đó. Nhiều module phụ thuộc cấu hình server và có thể bị phát hiện. Hãy đọc kỹ mô tả từng module trước khi dùng.

Vì sao có nhiều lớp obfuscation nếu addon miễn phí?

Mục tiêu là chống dịch ngược tự động: string vault, envelope mã hoá, VM bytecode, kiểm tra toàn vẹn và guard chống dump khiến decompiler và công cụ AI khó đọc logic. Người dùng cuối không phải trả gì và không phải xin key.
